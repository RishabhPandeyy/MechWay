
# 🔧 Vercel Root Directory Fix

## Problem: "The specified Root Directory 'server' does not exist"

This error occurs because Vercel can't find the "server" directory in your repository structure.

## ✅ SOLUTION 1: Check Repository Structure

### Option A: Verify GitHub Repository Structure
1. Go to your GitHub repository: https://github.com/YOUR_USERNAME/YOUR_REPO_NAME
2. Check if the "server" folder exists in the root directory
3. If missing, you need to push the "server" folder to GitHub

### Option B: Fix Repository Structure
```bash
# In your local repository
git add server/
git commit -m "Add server directory"
git push origin main
```

## ✅ SOLUTION 2: Alternative Deployment Methods

### Method A: Deploy Entire Repository as Root
**If your repository structure is:**
```
your-repo/
├── server/
├── *.html files
├── *.css files
├── *.js files
```

**Deployment Steps:**
1. In Vercel Project Settings → Functions
2. Set **Root Directory** to: `.` (root, not "server")
3. The server will be accessible at the domain root
4. Update your frontend to call APIs at the root level

### Method B: Move Server Files to Root
**If you want simpler deployment:**

1. **Move server.js to root:**
   ```bash
   mv server/server.js ./
   mv server/package.json ./
   mv server/vercel.json ./
   ```

2. **Update package.json scripts:**
   ```json
   {
     "scripts": {
       "start": "node server.js"
     }
   }
   ```

3. **Set Root Directory to: `.` (root)**

## ✅ SOLUTION 3: Vercel CLI Deployment

If web interface continues to have issues:

1. **Install Vercel CLI:**
   ```bash
   npm install -g vercel
   ```

2. **Deploy from command line:**
   ```bash
   cd your-project
   vercel --prod
   ```

3. **Follow prompts:**
   - Set up and deploy? **Yes**
   - Which scope? **Your account**
   - Link to existing project? **Yes**
   - What's your project's name? **new-on-wheels**
