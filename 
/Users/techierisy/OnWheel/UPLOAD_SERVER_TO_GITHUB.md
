
# 🚨 CRITICAL: Upload Server Folder to GitHub

## Why This is Necessary

**The Error**: "The specified Root Directory 'server' does not exist"
**Root Cause**: Your `server/` folder exists locally but has NOT been uploaded to GitHub

Vercel deploys from your **GitHub repository**, not from your local files. If the `server/` folder isn't on GitHub, Vercel can't find it during deployment.

## ✅ REQUIRED STEPS TO UPLOAD SERVER FOLDER:

### Step 1: Check Current Git Status
```bash
cd /Users/techierisy/OnWheel
git status
```
You should see the `server/` folder listed as "Untracked files"

### Step 2: Add Server Folder to Git
```bash
git add server/
git status
```

### Step 3: Commit the Changes
```bash
git commit -m "Add server directory for backend deployment"
```

### Step 4: Push to GitHub
```bash
git push origin main
```
*(Replace "main" with your branch name if different)*

### Step 5: Verify Upload
1. Go to your GitHub repository: `https://github.com/YOUR_USERNAME/YOUR_REPO_NAME`
2. Check that you can see the `server/` folder with all files inside
3. Confirm `server.js`, `package.json`, `vercel.json` are visible

## 🔧 ALTERNATIVE: Quick Command Solution

